# هوية فنية — خرائط «مين المتنكر؟»

أسلوب: واقعية مبسّطة (Premium Stylized). الأبيض لون مساعد فقط. كل خريطة لها لوحة ألوان وخامات ولون جدران مختلف لكل غرفة.

## كيف تُطبَّق الألوان تقنيًا
- كل غرفة في بيانات الخريطة تحمل: `wc` (لون الجدار)، `dado` (الشريط السفلي حتى 1.05م)، `trim` (الإفريز)، و`floor` + `c1/c2` (نوع الأرضية ولونها).
- الجدار المشترك بين غرفتين يُرسم بنصفين، كل نصف بلون الغرفة التي تواجهه (المحرّك يقسّم الجدار تلقائيًا عند حدود الغرف).
- أنواع الأرضيات المولّدة بالكود: stone, parquet, wood, tile, vinyl, epoxy, marble, diamond, confetti, carpet, concrete, grass.
- مواد الأصول: base, gloss, metal, glass, emis (مضيء), fabric, rubber — تُدمج بـDraw Call لكل مادة.
- الإضاءة: ACES، تعريض 0.84، ضوء بيئة (PMREM)، ضوء شمس واحد، وبقع إضاءة ملوّنة (بدون إضاءات ديناميكية لكل غرفة).

## ملاحظات صادقة
- الخامات إجرائية (Canvas) وليست ملفات PBR مضغوطة؛ لا يوجد Normal/AO map حقيقي ولا Baked Lighting. الانعكاس عبر envMap فقط.
- لا نماذج GLB/GLTF: كل المجسمات مولّدة بالكود ومدموجة (لا ملفات ثنائية).

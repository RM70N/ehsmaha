# UNSUPPORTED-ACTIONS

ما **لا** يمكن تنفيذه (أو لا يمكن ضمان تنفيذه) حالياً، مع السبب والمتطلب. هذه الوظائف **غير معروضة كأزرار** (لا زر يوحي بأنها تعمل). لم يُعدَّل أي ملف أصلي لتجاوزها.

> **عن شرط «10 أزرار لكل قسم»:** بلغ العدد 10 أو أكثر في 9 أقسام (اللاعبون، الرسائل، التحليلات، السيرفر، الأعضاء، الحماية، الأمان، الإعدادات، التدقيق). في بقية الأقسام اكتفيتُ بما له **آلية حقيقية قابلة للتحقق**، ولم أُكرّر وظائف لإكمال العدد (كما طلبتَ). الجدول يبيّن النقص وأسبابه.

## ب) وظائف مطلوبة غير قابلة للتنفيذ حالياً

| الوظيفة | الحالة | السبب الدقيق | المتطلب لتفعيلها |
|---|---|---|---|
| تقييد لاعب من الألعاب / تعطيل شاته / إزالته من المتصدرين | UNAVAILABLE | لا حقول ولا قواعد تفرض ذلك في الموقع (`leaderboards` مفتاحه الستريمر وتكتب فيه أجهزة اللاعبين) | تعديل في الموقع يقرأ حقل تقييد ويفرضه |
| إعادة تسمية يوزر قسرياً | UNAVAILABLE | يمسّ `usernames` و`users` وفهارس متعددة — لم يُثبَت مسار آمن | تحديد مسار الموقع الرسمي (`usernameChangedAt`) |
| نظام الضحك/الترفيه (تحديات يومية، سجل مواقف طريفة…) | UNAVAILABLE | لا يستهلكه الموقع؛ وبناؤه كمجموعات بديلة يخالف «لا مصدر حقيقة موازٍ» | قرار منتج + تعديل في الموقع |
| ساعات الذروة | UNAVAILABLE | لا طوابع زمنية لكل جولة بمصدر قابل للاستعلام الفعّال (RTDB `opsEvents` غير مفهرس) | فهرسة/تجميع في الموقع |
| إحصاءات استخدام الأوامر وآخر أخطاء كل أمر | UNAVAILABLE | `utils/usageStats.js` بالذاكرة فقط ولا يكتب سجلاً | endpoint داخل البوت أو كتابة سجل في قاعدته |
| تقييد أمر برتبة أو روم محددة | UNAVAILABLE | Discord يتطلب OAuth Bearer لمدير السيرفر لـ`/commands/{id}/permissions`؛ والبوت لا ينفذ تقييداً داخلياً | Adapter داخل البوت يفحص قائمة تقييد من قاعدته |
| تعطيل أمر **داخل** البوت (دون إلغاء تسجيله) | BLOCKED | `interactionCreate.js` لا يفحص أي قائمة تعطيل | Adapter داخل البوت (لم أعدّل ملفاته) |
| إعادة تحميل خدمة بالبوت دون إعادة تشغيل | BLOCKED | لا endpoint إداري يعيد تحميل `streamerAnnouncer`/الكاش؛ `/health` فقط | `POST /admin/reload` داخل البوت أو Sidecar في نفس العملية |
| تفعيل إضافة/إزالة ستريمرات البوت فوراً | PARTIAL | تُحفظ في القاعدة وتظهر «معلّق»؛ تُحمَّل عند الإقلاع | نفس المتطلب السابق |
| قراءة قاعدة بوت على Render بلا PostgreSQL | BLOCKED | SQLite محلي في حاوية البوت | `DATABASE_URL` للبوت (وللّوحة `BOT_DATABASE_URL`) |
| حالة البوت (Ping/Uptime) | يعتمد | تتطلب `BOT_HEALTH_URL`؛ وإلا «غير متاح» | ضبط المتغير |
| استهلاك الموارد (CPU/RAM) | UNAVAILABLE | لا مصدر موثوق خارج منصة الاستضافة | ربط Render Metrics API |
| إدارة قنوات/رتب Discord (إنشاء/حذف/صلاحيات) | NOT IMPLEMENTED | ممكنة عبر REST ولم تُبنَ في هذا الإصدار | مرحلة قادمة |
| زر استعادة النسخة الاحتياطية من الواجهة | BY DESIGN | استبدال قاعدة حية خطر؛ الإجراء يدوي موثّق في README | — |
| إعدادات الموقع العامة غير الألعاب (إشعارات، رسائل…) | UNAVAILABLE | لا واجهة رسمية/مخطط لها في الموقع | — |
| نسخ احتياطي لـFirestore/RTDB الموقع | OUT OF SCOPE | تُدار من Firebase (Scheduled exports) | — |
| 2FA لحسابي الدخول | NOT IMPLEMENTED | خارج النطاق المطلوب | TOTP مستقبلاً |

## ج) البنود المستبدلة بآلية بديلة حقيقية

| المطلوب | البديل المنفَّذ |
|---|---|
| «حظر لاعب» | تعطيل حساب Firebase + سحب الجلسات (يمنع الدخول فعلاً) — مؤقتاً بمجدول يعيد التفعيل ويتحقق |
| «تعطيل لعبة» | شارة `maintenance` (الموقع يعطّل بطاقتها) — البيانات لا تُمسّ |
| «حظر ستريمر» | `bridgeStreamers.enabled=false` (خادم الربط يرفض الاتصال) |
| «إعادة مزامنة الأوامر» | تقرير انحراف (ملفات ↔ Discord)؛ المزامنة الفعلية يجريها البوت عند التشغيل |
| «تعطيل أمر» | إلغاء تسجيله من Discord وإعادته بنفس التعريف |

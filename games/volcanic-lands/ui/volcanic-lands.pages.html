🔑 مفتاح API — تيك توك
اربط مفتاح تيك توك مرة وحدة من بروفايلي (اضغط اسم حسابك فوق بالزاوية اليمنى) وبيشتغل تلقائياً هنا وبكل الألعاب.
🟣 ربط بث تويتش — بدون مفتاح!
1
تأكد إن بثك شغال على تويتش الآن
2
اكتب اسم قناتك بالضبط في الحقل تحت (نفس اللي بعد twitch.tv/)
3
اضغط ابدأ اللعبة — يتصل بشات بثك تلقائياً بدون أي API Key!
🟢 ربط بث كيك — بدون مفتاح!
1
وأنت بثك شغال على كيك، افتح بمتصفحك الرابط: kick.com/api/v2/channels/اسم_قناتك
2
دوّر (Ctrl+F) عن كلمة "chatroom" وبعدها "id": — انسخ الرقم اللي بعدها
3
الصق الرقم بحقل Chatroom ID تحت واضغط ابدأ اللعبة
▶️ ربط بث يوتيوب — يحتاج مفتاح مجاني
1
روح console.cloud.google.com وفعّل YouTube Data API v3
2
أنشئ API Key وانسخه، والصقه بحقل المفتاح تحت
3
انسخ رابط البث المباشر (أو رقم الفيديو) والصقه بالحقل تحت

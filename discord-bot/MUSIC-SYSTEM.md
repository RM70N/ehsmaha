# 🎵 نظام الموسيقى — احسمها

البوت يدخل الروم الصوتي، يشغّل الأغاني (بالاسم أو برابط YouTube / Spotify)، ويتحكم الجميع بلوحة أزرار تتحدث تلقائياً.

## الأوامر
| Slash | بادئة | الوظيفة |
|---|---|---|
| `/اغنية` | `!اغنية` | اسم أغنية/فنان (نتائج تختار منها) أو رابط YouTube أو Spotify (أغنية) |
| `/قائمة` | `!قائمة` | قائمة الانتظار مع تقليب الصفحات (الاسم، الفنان، المدة، الغلاف، من طلبها) |
| `/تخطي` | `!تخطي` | تخطي الأغنية الحالية |
| `/ايقاف` | `!ايقاف` | إيقاف وخروج من الروم |
| `/موسيقى` | `!موسيقى` | يعيد اللوحة الحالية + إحصائيات الجلسة |

> أوامر `!` تحتاج **Message Content Intent** مفعّل (Developer Portal → Bot). بدونه استخدم الأوامر `/` — تعمل بنفس الوظائف.

## لوحة التحكم (تتحدث نفس الرسالة)
⏪ 10ث · ⏸️ إيقاف مؤقت · ▶️ استكمال · ⏩ 10ث / 🔄 من البداية · ⏭️ تخطي · 🔂 تكرار الأغنية · 📜 القائمة / 🔀 عشوائي · 🔁 تكرار القائمة · ⏹️ إيقاف وخروج.
التقديم/الترجيع/الإعادة تعيد تشغيل المصدر من الموضع المطلوب (`ffmpeg -ss`) بدون المساس بالجلسة الصوتية.

## القواعد
- العضو لازم يكون **بنفس الروم الصوتي** للجلسة ليتحكم (يُفحص عند كل ضغطة). عضو بروم ثاني أو خارج الرومات ← رد خاص (Ephemeral).
- البوت ما ينتقل لروم ثاني أثناء جلسة نشطة. جلسة مستقلة لكل سيرفر.
- يغادر تلقائياً بعد انتهاء القائمة (`MUSIC_IDLE_LEAVE_SECONDS`)، أو لو الروم فضي من البشر (`MUSIC_EMPTY_LEAVE_SECONDS`)، أو إيقاف مؤقت طويل.
- اسم البوت **داخل السيرفر** (nickname) = اسم الأغنية الحالية، ويرجع الأصلي بعد الجلسة (حتى بعد توقف مفاجئ). لا نغيّر اسم/صورة حساب البوت العامة (محدودة بمرتين بالساعة وتؤثر على كل السيرفرات) — صورة الأغنية تظهر باللوحة.
- Spotify: نقرأ اسم الأغنية/الفنان/المدة فقط ونبحث عن نسخة مطابقة قابلة للتشغيل. ما نتجاوز DRM. لو ما لقينا نسخة مطابقة ← رسالة واضحة (لا نشغّل أغنية ثانية). المدعوم: رابط أغنية (track) فقط.

## ⚠️ مصدر الصوت (مهم جداً)
الصوت يُستخرج عبر **yt-dlp** (يُنزَّل تلقائياً أول مرة لـ`data/bin/yt-dlp`) + **ffmpeg**.
**YouTube يحجب كثيراً من عناوين الاستضافات** برسالة «Sign in to confirm you're not a bot». البحث يشتغل غالباً، لكن **تشغيل الأغنية يفشل** من هذي العناوين، والبوت يرد برسالة واضحة بدل ما يدّعي التشغيل. الحلول (متغيرات بيئة):
1. **كوكيز** (الأضمن): صدّر cookies.txt (Netscape) من متصفح مسجّل دخول بحساب ثانوي، وحط `YTDLP_COOKIES_FILE=/المسار/cookies.txt` أو `YTDLP_COOKIES_B64=<base64 للملف>`.
2. **بروكسي سكني**: `YTDLP_PROXY=http://user:pass@host:port`.
3. أحياناً يفيد: `YTDLP_JS_RUNTIME=node` أو `YTDLP_PLAYER_CLIENTS=tv,web_safari` (خصوصاً مع الكوكيز).
الكوكيز/البروكسي أسرار — ضعها بمتغيرات بيئة الاستضافة فقط، ولا ترفعها للريبو.
ذاكرة الاستضافة المحدودة: نشغّل عملية yt-dlp **واحدة بالوقت** (طلبات البحث تنتظر دورها).

## متغيرات البيئة (كلها اختيارية)
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `MUSIC_ENABLED` | `on` | `off` يوقف النظام |
| `MUSIC_PREFIX` | `!` | بادئة أوامر الرسائل |
| `MUSIC_MAX_QUEUE` | `50` | أقصى عدد بالقائمة |
| `MUSIC_MAX_TRACK_SECONDS` | `7200` | أطول أغنية مسموحة |
| `MUSIC_IDLE_LEAVE_SECONDS` | `120` | الانتظار قبل المغادرة بعد انتهاء القائمة |
| `MUSIC_EMPTY_LEAVE_SECONDS` | `60` | المغادرة لو الروم فضي من البشر |
| `MUSIC_PAUSE_LEAVE_SECONDS` | `600` | المغادرة بعد إيقاف مؤقت طويل |
| `MUSIC_DUPLICATE_WINDOW_SECONDS` | `30` | منع تكرار نفس الأغنية خلال هذي المدة |
| `MUSIC_SEARCH_RESULTS` | `5` | عدد نتائج البحث |
| `MUSIC_SEEK_SECONDS` | `10` | مقدار التقديم/الترجيع |
| `MUSIC_PANEL_REFRESH_SECONDS` | `15` | تحديث شريط التقدم |
| `MUSIC_NICKNAME` | `on` | اسم البوت = اسم الأغنية |
| `MUSIC_ADMIN_ONLY` | — | قيود للمشرفين، مثال: `skip,stop` أو `تخطي,ايقاف` (الإجراءات: back,fwd,pause,resume,restart,skip,repeat,shuffle,loopq,stop) |
| `MUSIC_BITRATE` | `128k` | جودة الترميز |
| `YTDLP_PATH` / `YTDLP_AUTO_DOWNLOAD` | — / `on` | مسار yt-dlp أو منع التنزيل التلقائي |
| `YTDLP_COOKIES_FILE` / `YTDLP_COOKIES_B64` / `YTDLP_PROXY` / `YTDLP_JS_RUNTIME` / `YTDLP_PLAYER_CLIENTS` | — | انظر أعلاه |
| `FFMPEG_PATH` | `ffmpeg` | مسار ffmpeg |

## المتطلبات
`ffmpeg` (مع libopus) على الخادم، و`@discordjs/voice` + `libsodium-wrappers` (مثبّتان بـpackage.json، تشفير DAVE عبر `@snazzah/davey`). Intent: `GuildVoiceStates` (غير مميّز). صلاحيات البوت بالروم الصوتي: Connect + Speak، وChange Nickname لاسم الأغنية.

## الملفات
`music/` — `MusicManager` (جلسات + تحقق) · `MusicPlayer` (اتصال + ffmpeg + تحكم) · `MusicQueue` (قائمة وأوضاع) · `MusicExtractor` (yt-dlp/Spotify) · `MusicControls` (أزرار + منطق الأوامر) · `MusicEmbeds` (التصميم) · `MusicEvents` (!prefix + حالة الصوت) · `MusicIdentity` (اسم البوت) · `MusicConfig`. الأوامر: `commands/music/*`، الحدث: `events/voiceStateUpdate.js`.

# تقرير اختبار تطبيق احسمها لويندوز

تاريخ التشغيل: 2026-11-04 • بيئة الاختبار: Linux + Xvfb + Electron 38.8.6 + Playwright (`_electron`).
Firebase **وهمي** في اختبارات E2E (لا إنترنت لـgstatic داخل البيئة)؛ جسر الإشعارات وتسليم الدخول يُختبران
على Firebase الوهمي، لا على Firebase الحقيقي.

## ما لم يُختبر (بصدق — لا يُعدّ ناجحاً)

- **بناء `ehsmaha-setup.exe` وتثبيته**: لا يمكن هنا (لا Wine/ويندوز). جرّبت `electron-builder --win` على Linux وفشل
  (`spawn wine ENOENT`) ولم ينتج `latest.yml`؛ لذلك **لا يوجد EXE موثوق من هذه البيئة**. البناء الحقيقي يتم في
  `desktop-release.yml` على `windows-latest` مع `verify-dist.js` (sha512/إصدار/MZ). **لم يُشغَّل بعد على GitHub.**
- **إشعارات ويندوز الفعلية** (Toast، Focus Assist، شاشة القفل، الصوت، النقر من مركز الإشعارات): اختُبر المنطق عبر
  Notification وهمي مسجِّل. يلزم اختبار يدوي على ويندوز.
- **تصغير النافذة (minimize)**: Xvfb بلا window manager لا ينفّذه؛ اختُبرت حالة الإخفاء، وحالة minimized مغطاة بالوحدة فقط.
- **تسجيل جوجل الحقيقي** (`desktop-auth.html` + Firebase + تفويض النطاق `ehsmaha.com`): لم يُختبر؛ الصفحة تُنشر مع الموقع
  بعد الدمج، ويلزم تجربة يدوية. تأكد أن `ehsmaha.com` ضمن Authorized domains (مضاف أصلاً لتسجيل الموقع).
- **تحديث التطبيق عبر electron-updater/GitHub Releases**: غير قابل للاختبار قبل نشر إصدارين فعليين.
- **الألعاب ثلاثية الأبعاد فعلياً، OBS، GPU حقيقي، أداء/تسرب ذاكرة طويل المدى، جسور TikTok الحية**: لم تُختبر.
- **التوقيع الرقمي**: غير مفعّل (لا شهادة).
- **التزامن مع الموقع الحيّ**: يعتمد على نشر `content-manifest.json` بواسطة `pages.yml` بعد الدمج؛ قبل ذلك التطبيق يعمل
  بالنسخة المضمّنة (فشل جلب الـmanifest غير مؤذٍ).

## ملاحظة تشغيلية

اختبار تحت Xvfb كشف خطأً حقيقياً أُصلح: مؤقّت الأمان (12 ثانية) كان يعيد إظهار نافذة أُخفيت بالـTray؛ صار يعمل مرة واحدة فقط.
